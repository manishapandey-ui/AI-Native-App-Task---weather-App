Weather Intelligence App

A lightweight, responsive web app generated via Google AI Studio App Build and deployed through Cloudflare Pages.

* Core Features: City search, current weather conditions, 7-day forecast cards, visual temperature charts, and dynamic activity recommendations.


* API Integration: Public Open-Meteo Geocoding and Forecast APIs.


* Deployment: Continuous delivery to Cloudflare Pages via direct GitHub synchronization.


* Tech Stack: React, Vite, Tailwind CSS, and Lucide Icons.
